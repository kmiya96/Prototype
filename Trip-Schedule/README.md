# 旅のタイムライン

旅程を組み立てて、家族と共有するタイムライン。
サーバー不要・通信不要（オフラインでも開けます）。

---

## GitHub Pages で公開する手順

所要 5分。GitHubのアカウントだけあれば、ターミナルもgitコマンドも使いません。

1. GitHub にログイン → 右上の **＋** → **New repository**
2. 設定
   - Repository name: `trip-timeline`（好きな名前でOK）
   - **Public** を選ぶ ※Pagesは無料枠だとPublicのみ
   - 「Add a README file」は**チェックしない**
   - **Create repository**
3. 出てきた画面の **uploading an existing file** をクリック
4. `index.html` と `README.md` をドラッグ&ドロップ → 下の **Commit changes**
5. リポジトリ上部の **Settings** → 左メニュー **Pages**
6. Source を **Deploy from a branch**、Branch を **main** / **/(root)** → **Save**
7. 1〜2分待ってから Settings > Pages を再読み込み。
   `https://<あなたのID>.github.io/trip-timeline/` が表示されます。これが公開URL。

以降、旅程の初期値を変えたいときは GitHub 上で `index.html` を開いて鉛筆アイコンから編集 → Commit。
1〜2分で反映されます。

## 使い方

### 組み立てる / しおり
ヘッダー左のスイッチで切り替え。
- **組み立てる**：カードをドラッグして入れ替え。日をまたいだ移動もできます。
- **しおり**：読むだけの見た目。家族に見せるのはこちら。

### 時刻の考え方
- `◆` が付いた予定＝**時刻を固定**したもの
- 固定していない予定は、前の予定の終わり＋移動時間で自動的に決まります
- だから並び替えると、後ろの時刻が全部ついてきます

### 警告
- **● 間に合いません** … 前の予定から続けると、固定した時刻に着けない
- **▲ 閉まる時刻を過ぎます** … 「閉まる時刻」を入れたスポットで超過
- **要確認**（移動の継ぎ目が赤） … 並び替えで前の場所が変わった。所要時間を人間が確認してください

### 共有
- **共有する** → リンクをコピーして LINE などに貼る
  旅程まるごとがURLに入っています。サーバーには何も保存されません。
- **書き出す** → Markdown をコピー。メモアプリやNotionに貼る用。

## 制約（承知のうえで使ってください）

- **リンク共有は送った瞬間のスナップショット。** あとから直しても相手の画面は変わりません。送り直してください。相手が直した内容がこちらに返ってくることもありません。
- **共同編集はできません。** 必要になったら Firebase / Supabase などのバックエンドが要ります。
- **保存先はブラウザのlocalStorage。** ブラウザのデータを消すと旅程も消えます。大事な内容は「書き出す」でMarkdownを取っておいてください。端末をまたいだ同期もありません。
- **移動時間は手入力。** 地図APIを使っていないので、自動計算・自動再計算はしません。並び替えたら「要確認」が出るので、人間が直してください。
- **リンクは6,000文字前後になります。** アプリによっては長すぎて途中で切れることがあります。切れたらMarkdownを使ってください。
